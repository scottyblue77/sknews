Mit GitHub synchronisieren

Mit einem Token speichert das Dashboard neue Begriffe, Quellen und Bewertungen direkt in deinem Repo und startet sofort einen neuen Abruf. Ohne Token bleibt alles nur in diesem Browser.

Token anlegen: GitHub → Settings → Developer settings → Fine-grained tokens. Nur dieses Repo, Rechte Contents: Read and write und Actions: Read and write.

Der Token wird nur in diesem Browser gespeichert.
